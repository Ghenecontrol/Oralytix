Every part of the review, built as its own tool

Four features carry most of the weight of the product. Each one addresses a specific point where imaging review loses time, and each is worth its own explanation.

Review

Interactive image overlay

Findings live directly on the radiograph — click a highlighted region for the tooth number, description, and model confidence.

Explore this feature
Approval

Dentist review & approval

Every finding sits behind confirm, dismiss, or modify. Nothing reaches the patient chart without a decision attached to it.

Explore this feature
History

Imaging timeline & comparison

Prior studies align automatically by date, with side-by-side, overlay, and difference views to check what's changed.

Explore this feature
Quality

Image quality assistant

Exposure, positioning, and cropping are checked before analysis runs, so a blurry film gets flagged, not confidently misread.

Explore this feature
Also included

Smaller tools that make the four above work better

    Automatic tooth detection

    Every visible tooth is identified and numbered, giving every finding, note, and prior treatment a fixed address to attach to. It's what the overlay, approval, and timeline features all build on.

  2. ＋

    AI-assisted clinical notes

    A quick note like "46 looks suspicious" is expanded into a structured chart entry the dentist edits before saving — see this in context on the how it works page.

  3. ＋

    Patient explanation mode

    The same finding, described twice — clinical language for the chart, plain language for the conversation across the room. The dentist controls what's shown.
